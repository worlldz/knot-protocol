KNOT makes agent payments conditional.

KNOT is a programmable payment policy layer for autonomous agents on Arc. It lets USDC move only after the purchased work satisfies verifiable delivery rules.

The problem

Agents can pay. Payment does not prove delivery.

If an autonomous agent buys data, a risk score, an API result, or another machine service, the payment rail alone cannot tell whether the work was fresh, signed, complete, or useful.

01

Blind payment is risky

A provider can answer, but the answer may be stale or malformed.

02

Manual review breaks autonomy

Humans checking every result defeats the point of agent commerce.

03

Rules need to live before settlement

The buyer should define evidence gates before USDC is released.

The solution

One obligation. Multiple providers. One verified settlement.

The buyer defines the payment policy: maximum price, data freshness, response schema, latency, and provider signature. KNOT routes the request and pays only the provider that satisfies every condition.

Arc and Circle fit

Stablecoin-native infrastructure is the point.
